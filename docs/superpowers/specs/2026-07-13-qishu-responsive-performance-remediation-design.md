# 启枢页面响应式与性能修复设计

## 目标

在不改变启枢页面内容结构、品牌语气和主要视觉风格的前提下，修复首次访问像“打不开”、390px 手机局部裁切、1024px 横屏布局过密、2K/4K 显示比例偏小，以及低性能设备动画负载过高的问题。

目标页面为 `qishu-ai.html`，生产站点为 `https://qishu-ai-20260713.netlify.app`。

## 已确认根因

1. 页面使用至少 650ms 的阻塞式全屏加载遮罩，并在加载期间锁定页面滚动；跨境网络首字节波动会放大等待感。
2. 390px 视口下，空间建模轮播的网格子项受固有最小宽度影响，约 476px 的卡片被 351px 容器裁切；视频模块也存在同类最小宽度问题。
3. 主响应式断点设为 900px，导致 1024px 横屏过早进入桌面五列布局。
4. 主内容宽度封顶 1500px/1800px，标题封顶 104px；在 2160px 宽屏上，1500px 约为屏幕宽度的 69%。
5. 页面包含约 2088 个 DOM 节点、25 个章节、3 个 Canvas 和 133 个动画目标，持续动画没有统一按可见性和设备能力降级。
6. Netlify 海外链路不是纯前端代码可以消除的问题；国内 CDN 需要可用自定义域名、DNS 权限及相应合规条件。

## 方案比较

### 方案 A：保守补丁

只缩短加载动画、修补两个溢出点。改动最小，但不能解决 1024px、2K/4K 和低性能设备负载问题。

### 方案 B：平衡修复（采用）

保留当前页面结构和视觉语言，建立加载、响应式和动画性能令牌；修复断点与固有宽度；增加超宽屏规则；让 Canvas 和持续动画按视口可见性、低性能条件及 reduced-motion 状态暂停或降级。

### 方案 C：重构页面

拆分单页 CSS/JS、重构 25 个章节和动画系统。长期收益最大，但超出本轮“按顺序修复”的范围，回归风险也更高。

## 设计

### 1. 加载体验

- 加载遮罩不再等待固定 650ms，DOMContentLoaded 后立即进入短淡出。
- 加载遮罩的最长阻塞时间不超过 1200ms；即使脚本或资源异常，也必须解除 `body.is-loading`。
- 遮罩隐藏后立即取消交互拦截；视觉淡出控制在约 220ms。
- 页面切换仍可使用遮罩，但不得锁住浏览器返回缓存恢复流程。

### 2. 手机与平板响应式

- 将启枢融资页的紧凑布局上限从 900px 扩展到 1180px，1024px 横屏使用平板布局。
- 390px 下所有轮播、视频卡、图表和内容网格必须满足 `min-width: 0` 与 `max-width: 100%`。
- 手机空间建模轮播改为单列静态卡片，不依赖横向动画；单卡宽度不得超过内容容器。
- 可横向滚动的数据图表继续保留显式滚动容器，不通过 `body { overflow-x: hidden }` 掩盖溢出。
- 关键正文不得小于 13px；辅助标签不得小于 11px。

### 3. 2K/4K 大屏

- 在 1920px 以上引入宽屏令牌，让主要内容宽度从 1500px 平滑增长到最高 2160px。
- 启枢首屏标题在超宽屏上可增长到 132px，正文和卡片间距同步增长，但保持可读行长。
- 2560px 屏幕上的主要内容占比目标为 76%–84%，不使用整体 `zoom` 或 `transform: scale()`。
- 4K 屏仍保留适度外边距，避免内容贴边。

### 4. 动画与渲染性能

- Canvas 动画仅在其容器接近视口且页面可见时运行；离屏或后台标签页暂停。
- 低性能模式覆盖：`prefers-reduced-motion`、窄屏、低核心数或省流量状态；在这些条件下使用静态画面或低帧率降级。
- 不新增持续布局属性动画；保留的动效只使用 transform 和 opacity。
- 首屏以外的视频维持 `preload="none"`，仅在接近视口时加载 metadata。
- 本轮不重构全部生成器，但确保启枢页面不会同时运行不在视口中的多个 Canvas 循环。

### 5. 测试与验收

自动测试必须验证：

- 加载最短等待不再是 650ms，存在最长 1200ms 的解锁保护。
- 1180px 断点覆盖启枢紧凑布局。
- 390px 轮播和视频模块具备 `min-width: 0`、`max-width: 100%` 约束。
- 存在 1920px 以上的宽屏规则，内容上限至少 1960px，标题上限大于 104px。
- Canvas 动画包含视口可见性与页面可见性暂停逻辑。

浏览器验收视口：390×844、768×1024、1024×768、1366×768、1440×900、1920×1080、2560×1440、3840×2160。所有尺寸不得产生整页横向滚动；390px 不得裁切轮播首卡；1024px 不得使用五列摘要；2560px 主要内容占比不得低于 76%。

线上验收包括 HTTP 200、关键文案存在、三段视频支持 Range 请求、控制台无错误，以及首次可交互遮罩不超过 1200ms。

## 范围边界

- 不改十项精确修订的业务文案。
- 不重写页面为新框架。
- 不重新编码三段原始视频。
- 不在没有域名和 DNS 权限的情况下创建国内 CDN 配置。
